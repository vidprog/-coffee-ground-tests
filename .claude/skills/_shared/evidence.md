# Правила доказів

Спільне для всіх агентів. Заявка «працює» без доказу не приймається.

## Ієрархія доказів

1. **Падаючий → зелений тест.** Єдиний доказ, що щось справді виправлено.
2. **Зелена сюїта.** Доказ, що нічого не зламано поряд.
3. **Скріншот.** Доказ, що це виглядає так, як заявлено. Доповнює тест, не замінює.

Скріншот сам по собі не доводить фікс: він показує один момент і нічого не каже про регресії.

## Як робити скріншоти

```bash
node scripts/evidence.mjs before-12 --test flower
node scripts/evidence.mjs after-12 --test flower
node scripts/evidence.mjs feature-12 --mobile
```

Файли лягають у `docs/evidence/` і **комітяться в гілку PR**.

## Як показати скріншот у коментарі

Тільки через raw-посилання на гілку:

```markdown
![після](https://raw.githubusercontent.com/vidprog/-coffee-ground-tests/ГІЛКА/docs/evidence/after-12-result.png)
```

Артефакти GitHub Actions **не годяться** — їх не видно в коментарі, їх треба качати.

## Обовʼязковий мінімум

| Випадок | Докази |
|---|---|
| Баг виправлено | падаючий тест (текст падіння) + зелена сюїта + скріншоти «до» і «після» |
| Баг не відтворився | список виконаних кроків + скріншот поточної поведінки + питання авторові |
| Фічу зроблено | тест на кожен критерій + зелена сюїта + скріншот десктоп і мобільний |
| Здався (`needs-human`) | що пробував + що побачив + 2–3 гіпотези з посиланнями на рядки |

## Чесність

Тест не запускався — так і напиши. Скріншот не вийшов — напиши чому.
Вигаданий результат прогону виявляється за хвилину і знищує довіру до всього пайплайну.
