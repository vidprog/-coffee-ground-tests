# Тести на кавовій гущі ☕🔮

Жартівливі езотеричні тести — чистий фронтенд, без бекенду і без збірки.

## Тести

| | Тест |
|---|---|
| 🌸 | Яка ти квітка |
| 🎭 | Який ти герой мультфільму |
| 🍕 | Яка ти страва з холодильника о 3-й ночі |
| 🔮 | Ким ти був у минулому житті |

По 5 питань, 4 можливі результати в кожному. Кожна відповідь дає +1 бал одному з архетипів, варіанти перемішуються при кожному проходженні.

## Запуск

```bash
open index.html
```

Або будь-який статичний сервер:

```bash
python3 -m http.server 8000
```

## Структура

- `index.html` — три екрани: вибір тесту → питання → результат
- `data.js` — контент усіх тестів
- `styles.css` — езотерична тема (нічне небо, золота типографіка, фази місяця)
- `app.js` — логіка тестів і зоряний canvas

Шрифти підвантажуються з Google Fonts; офлайн підхопиться системний fallback.
